# Roadmap

What the code says is changing. Nothing about what anyone intends.

## Rules for this page

- Every entry rests on a deprecation, an API version, or an unreleased note.
- A deprecation entry names the symbol, the module, and the replacement its
  doc comment names.
- Where `deprecations` reports a `total` above the symbols listed, say how many
  more there are rather than inventing them.
- An alpha or beta API version is evidence that a stable version is intended,
  and that is all it is evidence of.
- No dates. No priorities. No commitments the code does not carry.

## Shape

## Deprecations

A table: symbol, module, replacement.

## API versions

The versions present and what their stability level means for a caller.

## Unreleased

What the unreleased notes name, where they exist.
